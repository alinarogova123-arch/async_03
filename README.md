# Minechat

Интерфейс для чата бабушки Зины.

## Подготовка окружения

Вам понадобится CLI Linux и установленный Python 3.14.

Установите Tkinter:

```
sudo apt-get install python3-tk
```

Скачайте репозиторий и перейдите в его директорию.

Установите зависимости:

```
pip install -r requirements.txt
```

## Запуск

Запустите интерфейс регистрации:

```
python3 registration.py
```

Введите предпочитаемый никнейм и нажмите "зарегистрироваться", закройте окно регистрации.

Запустите интерфейс чата:

```
python3 mainchat.py
```
